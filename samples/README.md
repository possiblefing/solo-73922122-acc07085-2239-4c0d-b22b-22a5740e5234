# 样例数据说明

## 01_amount_ambiguity —— 同额歧义

`bank.csv` 中 B001/B002 与 `system.csv` 中 S001/S002 同为 CNY 50000 分，
且日期两两相差不超过 2 天，构成 2×2 的歧义候选；B003/S003（8800 分）独立成组。

上传后预期分析结果：

* 整批最大配对数 = 3；
* **确定配对**只有 `B003-S003`（所有最优方案共有）；
* B001、B002 各自的可选配对均为 `[S001, S002]`（可参与某个最优方案，但没有任何一对被任选）；
* 没有必然未匹配行。

## 02_concurrent_lock —— 并发锁定与不可行锁定

候选配对构成链 `S102—B102—S101—B101`（B102-S101 日期差 2 天是合法候选边，
B101-S102 日期差 4 天不是候选边）。最大配对数 = 2，且 `B101-S101`、`B102-S102`
均为所有最优方案共有（确定配对）。

* 尝试锁定 `B102-S101`：虽是候选边，但锁定后最大配对数将降为 1，API 返回
  `422 lock_infeasible` 并保留原状；
* 两个客户端持同一修订号并发锁定不同配对：恰好一个成功（200），
  其余收到 `409 revision_conflict`，携带最新修订号重试即可成功。
